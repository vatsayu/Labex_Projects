# LABEX Projects

A practical, self-built project portfolio covering Linux, Bash, networking, Python, cybersecurity, DevOps, SOC operations, and security automation.

LABEX projects are inspired by practical project ideas and learning objectives. Each implementation is developed independently, tested in a controlled environment, documented, and published as part of this repository.

    ↓

    ↓

    ↓

* Source code

* Tests
* Documentation

* Sanitized sample output

## Security Scope

Security-related projects are performed only against systems that are owned by the project author, deliberately vulnerable laboratory systems, CTF environments, or systems for which explicit authorization exists.

Projects involving enumeration, credential testing, exploitation, reverse shells, privilege escalation, or similar activities are intended for controlled educational environments.
